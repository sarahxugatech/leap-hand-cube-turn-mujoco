# LEAP In-Hand Cube Face Turn

## Project goal

Use one LEAP hand in desktop Python MuJoCo simulation to turn one face of a cube by 90 degrees, starting from a stable held grasp and ending in a stable held grasp.

Full Rubik's Cube solving, two-hand work, pen spinning, hammer manipulation, hardware, learned policy, VLA, and MPC are out of scope.

## Method reference

Method reference: dexterous-astra (Jianglong Ye), sim / zero-shot script / policy folder structure, grasp-first ordering, and sampled keyframe planner pattern. LEAP model, poses, controller, and all numbers were re-implemented and measured in MuJoCo in this project; no Sharpa/Wuji code or checkpoints were copied.
