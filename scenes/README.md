# MuJoCo scenes

| Scene | Purpose |
|---|---|
| `table_cube.xml` | Frozen baseline table, free cube, and mounted LEAP Hand |
| `table_articulated_face_test.xml` | Control scene with a passive rotating face layer |

| `table_2x2_cube_test.xml` | Standalone 2×2 visual scene check |
